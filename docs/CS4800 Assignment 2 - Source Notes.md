## Page 1 — Assignment and requirements

Assignment 2 asks for the first deployed MVP of the final project and is worth 10 points. The due-date field directs students to Canvas.

The app must have a backend server, frontend, and database persistence; all stacks are allowed. Code must be pushed to GitHub and have a clean project structure. Deployment may use AWS EC2, Vercel, or another cloud service. Continuous integration is required.

The project timeline lists ideation on September 7, MVP deployment on October 19, the first 100 users on November 10, and final submission / presentation on December 1, all in 2026.

## Page 2 — Submission

Submit the public URL of the deployed web app in Canvas. The competition-manager URL shown in the PDF is an example submission URL, not a required project idea.

## Interpretation for planning

The prompt specifies the technical baseline, not the app’s product features. For example, a future record-creation workflow should save through the backend into the database and remain available when revisited. Actual entities and features await the student’s instructions.

The student reports professor approval for AI-assisted / vibe coding. That context comes from the student, not from an explicit AI-use policy in this PDF.

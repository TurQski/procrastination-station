# procrastination-station

Turn an overwhelming goal into a manageable first step. Built for the CS4800 final project.

## Development

Requires Node.js 22.12+ (22.x) and npm.

```sh
npm ci
npm run dev
```

Open http://localhost:3000. See [development and configuration](docs/DEVELOPMENT.md) for checks, architecture, and the proposed database setup.

Current increment: responsive landing page and a validated, deterministic plan preview. Previews are **not saved**; database persistence, private user access, dashboard, and deployment are upcoming increments.

Original requirements and assignment notes are preserved in [docs](docs/).
